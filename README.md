# Flutter Music App

## About the Project

This is a simple music player application developed using Flutter and Dart. It demonstrates how to build a music player interface and play audio using the `just_audio` package.

## Features

- Display music tracks
- Play audio tracks
- Pause and resume music playback
- Control music playback
- Simple and user-friendly music player interface

## Technologies Used

- Flutter
- Dart
- just_audio package

## Concepts Learned

- `StatelessWidget`
- `StatefulWidget`
- `setState()`
- Audio playback using `just_audio`
- `AudioPlayer`
- `play()` and `pause()`
- Asset management in Flutter
- Reusable Custom Widgets
- UI Design using Flutter

## Project Structure

- `main.dart` – Entry point of the application.
- `music_screen.dart` – Displays the music player interface (if separated into this file).
- `asset/` – Stores audio files and other assets used in the application.

## Getting Started

1. Clone or download this repository.
2. Open the project folder in Android Studio or VS Code.
3. Run `flutter pub get` to install dependencies.
4. Run `flutter run` to launch the application.
